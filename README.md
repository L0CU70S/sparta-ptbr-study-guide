## Purpose

This repository documents an independent learning journey about the **SPARTA — Space Attack Research and Tactic Analysis** framework.

It provides educational material in Brazilian Portuguese for professionals and students interested in Space Cybersecurity, particularly in the following areas:

- Ground Segment Security
- Mission Operations Center (MOC) Security
- Link Security
- Blue Team and DFIR
- Threat Modeling
- Security Risk Assessment
- Critical Systems and OT/ICS Security Principles

The official SPARTA materials remain the authoritative source:

- [SPARTA — The Aerospace Corporation](https://sparta.aerospace.org/)
- [SPARTA FAQ](https://sparta.aerospace.org/resources/faq)
- [SPARTA Terms of Service](https://sparta.aerospace.org/terms-of-service)

## What this repository is

- A non-official Brazilian Portuguese study guide.
- A collection of original explanatory notes.
- A bilingual glossary of selected Space Cybersecurity terms.
- A set of fictional and defensive threat-modeling exercises.
- A place to document learning based on public sources.

## What this repository is not

- An official translation of SPARTA.
- A replacement for the SPARTA website or official documentation.

- A representation of The Aerospace Corporation or any space organization.

## Responsible use

This project focuses on defensive security, threat modeling, risk assessment, resilience, monitoring, incident response, and security architecture.

All diagrams, cases, examples, and scenarios are fictional or based on publicly available information. No real satellite, ground station, mission network, customer environment, credential, internal topology, or sensitive operational information is included.
